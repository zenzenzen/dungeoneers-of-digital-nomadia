# Digital Nomadia

A satirical digital-nomad source library and an independent browser party game. The active MVP is **Swipe Right, Regret Later**: one or more players in private rooms, including solo tests, random character cards, quick social encounters, negotiated help, sabotage, and fictional romance finales.

Original D&D material remains source evidence. The party mode has its own rules and executable content; do not migrate or rewrite the source library implicitly. Existing legacy workspace deletions predate this implementation and must stay preserved.

Implementation lives in `party-game/`. Start with its README and `docs/VERIFICATION.md` for current delivery evidence. Hosted verification and human pacing tests are separate from passing local checks.
