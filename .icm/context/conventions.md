# Conventions

Preserve original files, jokes, source prices, and prior workspace changes. Add party adaptations in `party-game/`; do not restore the deleted legacy Node workspace. The user authorized packaging the existing changes and removals in the launch PR. Record broad write scope in the touch manifest before source migration.

Keep original, adapted, and newly authored material distinguishable. Catalogue tags are inferred editorial candidates; playable approval is separate. Every playable effect must execute without D&D adjudication. Balance values belong in campaign/card data. Never invent currency exchange rates.

Use RTK for verbose CLI output. Apply the repository docpipe gate before large document reads; do not pack files being edited verbatim. Use Eloquent for documentation. Keep credentials and generated test room tokens in ignored files. Refresh/check ICM after structural changes.

Verification is claim-specific: source audit, mechanical simulation, real browser automation, Docker recovery, hosted smoke, and human playtesting establish different things.
